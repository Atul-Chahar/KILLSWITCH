Source: [First Commit](https://www.wemakedevs.org/aws/first-commit), [First Commit rules](https://www.wemakedevs.org/aws/first-commit/rules), [Bharat Builds rules](https://www.wemakedevs.org/aws/rules).

## Rules that bind the code

| Rule | What we do about it |
|---|---|
| Work starts at event opening and ends at the deadline | First commit on 17 Sep. Nothing copied from earlier repos |
| Prior work does not qualify, even rewritten | Every file in this repo is written during the event |
| Repository history mismatches disqualify the whole team | Commit steadily, real messages, no history rewriting, no backdating |
| Open-source libraries, frameworks, public APIs, boilerplate and starter templates are fine | CDK, Strands, React starters are allowed. Credit them |
| AWS usage must be demonstrable in the video | The video shows the Step Functions execution, the approval, CloudTrail evidence and the console |
| Anything you did not write needs a credit | `docs/CREDITS.md` |
| AI coding tools allowed, name them in the write-up | `docs/AI-TOOLS.md`, kept current, includes Claude Code and the ECC plugin |
| One submission per team, late is not scored | Submit by Saturday night if possible, do not wait for Sunday |
| No live demo, judging is on submitted material only | The video and README carry everything. Nothing important lives only in our heads |

## Judging criteria (what the README and video must answer)

1. **Idea and impact** — who is hurt by leaked keys, how much, how often.
2. **Built on AWS** — mandatory to win. A table of services, each with its job, each visible in the video.
3. **Learning demonstrated** — Step Functions approval tokens, CloudTrail forensics, Verified Permissions, Strands. Write the blog post.
4. **Execution quality** — tests, clean repo, honest limitations, reproducible demo.
5. **Demo video** — 3 minutes, a visible before and after.

## Side prizes worth grabbing

- **Best UI**: 1,00,000. The approval console is the one screen judges will look at. Make it good.
- **Top 5 blogs on AWS Builder Center**: Logitech keyboard. Write the blog on day 3, not day 4.
- Certificates for everyone who submits.

## Pre-submission checklist

- [ ] Repo is public, README complete, no secrets anywhere in history
- [ ] Live URL works from a fresh browser session
- [ ] 3-minute video uploaded and viewable without login
- [ ] Written summary: problem, solution, AWS usage
- [ ] `docs/AI-TOOLS.md` and `docs/CREDITS.md` filled in
- [ ] Limitations section is honest
- [ ] Every team member registered, AWS Builder Center student status verified
- [ ] Submitted through the stop's form, before the deadline
